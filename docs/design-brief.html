Aesthetic direction
✦ Academic-modern ✦ Trust-forward ✦ Warm-neutral base ✦ Structured clarity

The platform sits at the intersection of a trusted learning institution and a smart digital product. The aesthetic leans editorial and refined — think a high-quality university publication, not a startup landing page. Layouts use generous whitespace, a warm off-white base, and indigo as the primary accent to signal intelligence and trust. The discussion page shifts to a slightly warmer tone — more community, less institution.

One sentence to remember

"A knowledgeable friend who studied everything and just wants to point you in the right direction."

Tech stack constraints

Built on Ant Design + Tailwind CSS. The design system extends Ant Design's token system — never override AntD component internals; instead use theme tokens and Tailwind utilities for layout, spacing, and custom surface effects. Keep component logic inside AntD, visual decoration inside Tailwind.

Usage rules

Indigo = primary CTAs, active states, recommendation highlights, links. Amber = star ratings, course scores, "hot pick" labels only. Violet = AI/recommendation engine labels — keep it rare so it reads as special. Warm neutrals = all backgrounds and card surfaces. Never use pure white (#FFF) as a background — always #FAF9F7.

Section heading pattern
Serif 28px heading + indigo decorative underline (3px, 32px wide, offset below). Subheading in body size, muted color, max 2 lines. Always left-aligned — avoid centered headings except on hero.

Card entrance (page load)
Cards fade up staggered — 40ms delay per card, 300ms duration, ease-out. Only on initial load, not on filter change.
opacity: 0 → 1, translateY: 16px → 0; stagger-delay: calc(var(--i) * 40ms)
Card hover
Shadow transitions to indigo-tinted hover shadow. Slight scale up (1.015). Duration 180ms ease-out. No translateY lift — keeps cards grounded.
transform: scale(1.015); box-shadow: 0 4px 20px rgba(67,56,202,.12); transition: all 180ms ease-out
Match score bar (recommendation section)
Animate width from 0 to final value when section enters viewport. 600ms duration, cubic-bezier(.22,1,.36,1). Delay each bar by 80ms.
width: 0 → {value}%; transition: width 600ms cubic-bezier(.22,1,.36,1)
Discussion — new post appearance
New posts slide in from top with a subtle background flash (indigo-50 → transparent) over 800ms to draw attention without jarring.
translateY: -8px → 0, background: #E0E7FF → transparent; 300ms + 800ms
General principle
Max 1 hero animation per viewport. Prefer entrance animations (load/scroll-into-view) over continuous loops. All animations under 400ms except deliberate data reveals.
Always wrap in: @media (prefers-reduced-motion: no-preference)
Page purpose & tone

A community space where students compare courses, share experiences, and ask questions. Tone shifts slightly warmer and less institutional here — more peer-to-peer, less "smart system". Think Facebook Groups but with better typography and no visual noise.

Keep the same color palette and type system — just lean into warmer neutrals and reduce indigo usage. The AI accent (violet) disappears on this page entirely.

Layout structure
Left sidebar (240px)
Course filter nav — list of course names with unread count badges. Active course highlighted with indigo-left-border. Sticky. On mobile: collapses into a horizontal tab row.
Post feed (center, flex-1)
Each post: avatar (AntD Avatar, 36px) + username (13px/500) + timestamp (11px muted) in a row. Post body: 15px body text, max 3 lines collapsed with "read more". Reactions row: 👍 count, 💬 reply count, share icon — all as ghost buttons. Card style: white bg (#FFF this time, not FAF9F7), 8px radius, 1px warm border (#E8E5E0).
Right sidebar (280px)
"Most discussed courses" widget + "Trending topics" tags. Hidden on tablet, collapsed on mobile.
Compose box
Pinned at top of feed. AntD Input.TextArea, 3 rows, placeholder "Share your experience or ask a question…". Below: course tag selector + Post button (indigo, rounded-full). Subtle box-shadow to separate from feed.

One-time setup, forever reuse. After that, just open Claude Code in your project and say "refactor the course card UI" — it will already know the design system without you pasting anything.
4
Keep it updated. Whenever you evolve the design, update docs/design-brief.md and Claude Code stays in sync. You can also ask Claude (here in chat) to generate an updated brief anytime.
